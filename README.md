SNGA 是一个使用 SwiftUI 构建的原生 macOS 论坛客户端，它支持多账号登录、论坛浏览、话题互动、AI 辅助阅读、消息通知与常用资讯工具。

网络与解析层是站点无关的适配层，**NGA**、**NodeSeek** 和 **V2EX** 接在它上面 —— 同一套界面能同时用于三个论坛。

登录流程由各论坛的官方网页完成。SNGA 不保存密码，凭据按账号隔离保存。

> SNGA 是非官方客户端，与 NGA、NodeSeek、V2EX 官方均无从属关系。三个站点都没有提供稳定的公开 API，页面或接口调整可能导致部分功能暂时不可用。

## 2.0.0 更新

- 新增第三个论坛 **V2EX**：登录、节点与首页分类浏览、主题与回复、发回复、感谢、节点收藏、主题收藏、每日登录奖励、提醒、用户动态与节点搜索
- V2EX 的主题搜索接的是站点搜索框里的第三方 SoV2EX（V2EX 自己没有全文搜索），可按作者、发帖日期区间和排序方式筛。**关键词会发给 sov2ex.com，但不会带上你的登录状态**，档位名和搜索框下那句说明都写着提供方
- V2EX 的首页分类（技术、创意、Apple……）是站点把若干节点聚合起来的版面：打开后能看到它聚合了哪几个节点，也能按节点筛掉几个不看
- 措辞按各站自己的说法走：V2EX 管版面叫「节点」，侧栏那一栏因此叫「节点收藏」；它的「感谢」会花掉 10 个铜币而且撤不回来，所以点之前会先问一次；它的回复不渲染任何标记，编辑器那里连工具条都不画
- 新增 Base64：楼层里选中一段右键即可解码（**解得开才会出现这一项**，普通英文词不会误认）；写回复时可以单独写一段话、编成 Base64 插到光标处，正文其余部分照旧是人话
- 新增搜索历史：点搜索框就列出最近搜过的关键词，可逐条删除或一次清空；只记关键词，默认留最近 10 条，数量可在设置里调
- 修复：从 NGA 或 NodeSeek 切到 V2EX 时会弹出一句「论坛页面结构已变化」——上一个站的版面被拿去问了新账号的站点
- 修复：V2EX 上回复多的帖子打开特别慢。界面为了补作者属地会按楼层数逐个去拉资料，而 V2EX 一页 100 层；这两个站本来就报不出属地，现在不拉了（NodeSeek 同样受益）
- 修复：楼层里内嵌的视频被整个丢掉，连地址都不剩；现在换成一条能点的链接

## 支持的论坛

| 论坛 | 登录方式 |
| --- | --- |
| [NGA](https://bbs.nga.cn) | 官方网页登录 |
| [NodeSeek](https://www.nodeseek.com) | 邮箱验证码或账号密码，都走站点官方页面 |
| [V2EX](https://www.v2ex.com) | 账号密码，走站点官方页面（带图形验证码） |

三个站点共用同一套界面，账号各自独立，可以同时添加并随时切换。每个站点能做什么由它自己的适配层声明，界面据此决定画不画对应控件 —— 站点没有的功能不会画出来等你点了再报错。

各站的差别举几个例子：NGA 有子版面、话题评分和收藏夹分组；NodeSeek 的楼层表态里有「加鸡腿」，要花鸡腿且撤不回来；V2EX 自己没有主题搜索，那一档接的是它搜索框里的第三方 SoV2EX，而它的「感谢」会花掉 10 个铜币、同样撤不回来，所以点之前会先问一次。

## 主要功能

- 多账号添加、切换、重新登录与独立会话管理
- 论坛目录、搜索、收藏、最近访问、主板块与子板块浏览
- 站点自己摆在显眼处的版面固定在侧栏：V2EX 的首页分类（技术、创意、Apple……）一格聚合若干节点，点开还能按节点筛
- 搜索历史：点搜索框就列出最近搜过的关键词，可逐条删除或一次清空；只记关键词，默认留最近 10 条，数量可在设置里调
- 话题列表排序、分页、指定页跳转和置顶话题入口
- 话题骨架屏加载、分页、站内链接跳转及回到顶部
- 展示作者头像、等级、注册时间、IP 属地、徽章等资料，字段和叫法按各站自己的说法显示；V2EX 另有今日活跃度排名、公司职位、MOD/PRO 徽章和资料页上的外部链接
- 标注被管理处罚折叠的楼层，以及楼层发出后的改动时间
- 楼层末尾用一条分割线隔出作者签名，可在设置里关掉
- 支持图片、表情、表格、代码、引用、折叠内容、投票和楼层表态（NGA 另有话题评分）
- 支持话题回复、楼层引用、可视化编辑、源码编辑、预览与草稿保存，编辑器按站点给 UBB、Markdown 或纯文本的工具条（V2EX 的回复不渲染标记，所以那里连工具条都不画）
- Base64：楼层里选中一段右键即可解码（解得开才出现这一项）；回复编辑器里可以写一段话、编成 Base64 插到光标处，正文其余部分照旧是人话
- 同步话题收藏；NGA 还同步板块收藏与收藏夹管理
- 用户中心、短消息、通知、手动签到与签到统计，以及 macOS 系统通知
- OpenAI 兼容的 AI 用户画像与临时话题总结，支持 OpenAI、Ollama 等兼容服务
- 跟随系统、明亮、深色、NGA 暖金、午夜蓝及自定义共六套主题，无图模式、运行日志，以及无需登录即可使用的资讯热榜小工具

## 系统要求

- macOS 26.0 或更高版本
- Xcode 26.6 或更高版本
- Swift 6

项目主要使用 SwiftUI、SwiftData、WebKit、UserNotifications，以及固定版本的 [SwiftSoup 2.13.6](https://github.com/scinfu/SwiftSoup/releases/tag/2.13.6)。

## 构建与运行

1. 使用 Xcode 打开 `SNGA.xcodeproj`。
2. 选择 `SNGA` scheme 和 `My Mac`。
3. 等待 Swift Package Manager 下载依赖后运行应用。
4. 在应用内使用对应论坛的官方页面登录。

命令行 Debug 构建：

```sh
xcodebuild -project SNGA.xcodeproj \
  -scheme SNGA \
  -configuration Debug \
  -derivedDataPath .build/DerivedData \
  CODE_SIGNING_ALLOWED=NO \
  build
```

## 数据与安全

- 账号资料、收藏、草稿、偏好和签到记录保存在应用沙盒中
- 会话 Cookie 按账号隔离保存，普通请求不使用共享 Cookie 容器
- 帖子 HTML 会移除脚本、表单、iframe、事件属性和不安全链接
- 运行日志默认关闭，启用后不会记录 Cookie、登录令牌或请求正文
- AI API Key 保存在应用沙盒内权限 0600 的私有文件中，与会话 Cookie 同级；生成前会明确提示公开资料将发送到用户配置的 AI 服务
- 应用启用了 App Sandbox 和 Hardened Runtime

## 当前限制

- 不支持发布新话题或上传本地图片
- 不支持新建陌生人私信、删除私信或批量操作
- NodeSeek 尚不支持用户搜索、收藏夹分组，点赞发出后也撤不回（站点如此）
- V2EX 的首页分类不分页（站点就不给翻页），一屏之外的内容要去对应节点里看
- V2EX 没有站内私信，只有提醒；正文里的用户链接会交给浏览器打开（站点的用户地址里是用户名，换成编号要额外请求一次）
- V2EX 自己没有主题全文搜索，应用里那一档接的是站点搜索框中的第三方 SoV2EX：关键词会发给 sov2ex.com，但不会带上登录状态；可按作者、发帖日期区间和排序方式筛选
- V2EX 的提醒只有相对时间（站点不给绝对时刻），也没有未读状态 —— 打开提醒页时站点那边就已经清零了
- 不提供离线全文归档和自动更新
- 应用退出后不会签到、轮询消息或运行独立后台进程
- 尚未包含 Developer ID 签名、公证、安装包或 App Store 发布配置
